# Website Inter font subsets

These are the exact seven Inter variable WOFF2 subsets emitted by the reviewed
Next.js website build used for Android's shared-screen comparison on November
22, 2026. The existing hashed filenames are retained. They cover weights
100–900 and the website's Cyrillic, Greek, Vietnamese, extended Latin and Latin
Unicode ranges. Native uses the same face definitions and fallback metrics.

Upstream: <https://github.com/google/fonts/tree/main/ofl/inter>.
License: SIL Open Font License 1.1, in `OFL.txt`, obtained from that upstream.
The native asset inventory records the actual bytes and SHA-256 of each subset.
No network font request is needed when the installed app starts offline.
